# 115网盘秒传（MoviePilot V3）

将本地（含 qBittorrent 下载完成）的媒体文件**秒传**到 115 网盘，全程只读本地文件。

## 功能特性

- 🔑 **CK Cookie 登录**：填入网页 Cookie 即可，无需申请开放平台应用。
- 📱 **扫码登录自动填 CK**：发起扫码会话 → 用 115 App 扫码 → Cookie 自动获取并保存。
- 📁 **目录树明文可见**：网盘全目录（含递归子树）可浏览选择。
- 🗂️ **选择本地整个文件夹批量秒传**：扫描其下媒体文件逐个尝试秒传。
- ⚡ **监控 qB 下载完成秒传**：轮询下载器，下载完成即就地秒传。
- 🧹 **秒传成功且仍在 MP 整理队列时自动移除该队列项**（不再重复整理）。
- 🔁 **定时重试**：秒传失败且尚未被整理成功的文件按间隔自动重试。
- 🛡️ **只做「快传」**：未命中秒传时不把文件本体上传，绝不移动/改名/删除源文件。

## 说明

MoviePilot 没有「下载完成」事件，使用**周期轮询**下载器（qBittorrent `progress=1`）
来检测下载完成，因此「秒级」是相对轮询间隔而言（默认 15 秒，可调小到 5 秒）。

秒传成功条件 = 本地文件 sha1 + size 命中 115 服务器已有分块；未命中直接进入重试队列，
不会上传文件本体，因此不占用上行带宽。

## 配置说明

| 配置项 | 说明 | 默认 |
|---|---|---|
| 启用插件 | 总开关 | 关 |
| 115 Cookie | 网页登录 115 后复制（UID=...; CID=...; SEID=...） | 空 |
| 目标网盘路径 | 如 `/秒传`；留空=根目录 | 空 |
| 手动秒传目录 | 每行一个本地目录，其下媒体文件会被批量秒传 | 空 |
| 扩展名 | 逗号分隔；空=内置默认媒体扩展名 | 空 |
| 监控 qB 下载完成秒传 | 是否轮询下载器 | 开 |
| qB 轮询秒数 | 下载器轮询间隔 | 15 |
| 定时重试失败且未整理的文件 | 失败文件自动重试 | 开 |
| 重试间隔(秒) | 两次重试之间的间隔 | 600 |
| 秒传成功且文件在 MP 整理队列时移除该队列项 | 移除整理队列 | 开 |
| 发送通知 | 完成/失败通知 | 开 |

## 常见路径说明

- 秒传的目标目录通过「目标网盘路径」或目录树选择指定。
- 手动秒传目录是 **本地** 路径，必须是 MoviePilot 容器内可见的路径。
- qB 下载完成联动读取下载器中种子 `content_path / save_path+name`，所以种子所在目录
  必须在 MoviePilot 容器内可见（宿主与容器路径不一致时需做路径映射）。

## 接口

| 接口 | 说明 |
|---|---|
| `GET /api/v1/plugin/Mp115CloudPush/check_login` | 检查登录态 |
| `GET /api/v1/plugin/Mp115CloudPush/tree` | 网盘目录树 |
| `GET /api/v1/plugin/Mp115CloudPush/children?cid=` | 目录子项 |
| `POST /api/v1/plugin/Mp115CloudPush/qr/start` | 发起扫码 |
| `POST /api/v1/plugin/Mp115CloudPush/qr/poll` | 轮询扫码 |
| `POST /api/v1/plugin/Mp115CloudPush/push_path` | 手动秒传本地路径 |
| `POST /api/v1/plugin/Mp115CloudPush/retry/now` | 立即重试 |
| `GET /api/v1/plugin/Mp115CloudPush/status` | 状态/历史 |

## 依赖
